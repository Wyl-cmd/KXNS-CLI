# Kxns Hunter CLI

[![Version](https://img.shields.io/badge/version-1.0.0-green)](https://github.com/kxns-hunter/kxns-cli)
[![Python](https://img.shields.io/badge/python-3.12%2B-blue)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-MIT-yellow)](LICENSE)

**Kxns Hunter CLI** is a penetration testing focused AI agent that runs in the terminal, helping you complete security assessments, vulnerability analysis, and penetration testing tasks. It can read and edit code, execute shell commands, search and fetch web pages, and autonomously plan and adjust actions during execution.

## Features

- 🛡️ **Security Focused**: Specialized for penetration testing and security assessments
- 🔧 **Shell Integration**: Built-in shell command mode with Ctrl-X switch
- 🌐 **Web UI**: Built-in web interface for enhanced user experience
- 🔌 **MCP Support**: Model Context Protocol for extensible tool integration
- 📦 **Easy Deployment**: Simple installation scripts for Windows and Linux

## Installation

### Prerequisites

- Python 3.12 or higher
- pip (Python package manager)

### Quick Install

**Windows (PowerShell):**
```powershell
.\install.ps1
```

**Linux/macOS:**
```bash
chmod +x install.sh
./install.sh
```

### Manual Install

```bash
# Create virtual environment (optional but recommended)
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
# or
.\.venv\Scripts\Activate.ps1  # Windows

# Install dependencies
pip install -r requirements.txt

# Install in development mode
pip install -e .
```

## Configuration

### API Configuration

Configure your LLM API settings using the `api` command:

```bash
kxns api <url> <api_key> <model> [options]
```

#### Arguments

| Argument | Description | Required |
|----------|-------------|----------|
| `url` | LLM API base URL | Yes |
| `api_key` | LLM API key | Yes |
| `model` | LLM model name | Yes |

#### Options

| Option | Short | Description | Default |
|--------|-------|-------------|---------|
| `--max-context` | `-x` | Maximum context size in tokens | 128000 |
| `--image-input` | `-i` | Enable image input capability | False |
| `--thinking` | `-t` | Enable thinking mode | False |

#### Examples

```bash
# Basic configuration
kxns api https://api.openai.com/v1 sk-your-api-key gpt-4

# With custom context size
kxns api https://api.openai.com/v1 sk-your-api-key gpt-4 -x 200000

# Enable image input capability
kxns api https://api.openai.com/v1 sk-your-api-key gpt-4-vision -i

# Enable thinking mode
kxns api https://api.anthropic.com/v1 sk-your-api-key claude-3-5-sonnet -t

# Enable all capabilities
kxns api https://api.openai.com/v1 sk-your-api-key gpt-4-vision -x 200000 -i -t

# Custom API provider
kxns api https://apis.iflow.cn/v1 sk-your-api-key qwen3-coder-plus -x 128000
```

### Configuration File

Configuration is stored in `~/.kxns/config.toml`:

```toml
# Kxns Hunter CLI Configuration
# Generated by kxns api command

default_model = "qwen3-coder-plus"
default_thinking = true  # Only if -t is enabled

[models.qwen3-coder-plus]
provider = "custom"
model = "qwen3-coder-plus"
max_context_size = 128000
capabilities = ["image_in", "thinking"]  # Only if -i/-t is enabled

[providers.custom]
type = "openai_legacy"
base_url = "https://apis.iflow.cn/v1"
api_key = "sk-your-api-key"
```

#### Configuration Fields

| Field | Description |
|-------|-------------|
| `default_model` | Default model to use |
| `default_thinking` | Enable thinking mode by default |
| `models.<name>.provider` | Provider name for this model |
| `models.<name>.model` | Model identifier |
| `models.<name>.max_context_size` | Maximum context size in tokens |
| `models.<name>.capabilities` | Model capabilities: `image_in`, `thinking`, `video_in`, `always_thinking` |
| `providers.<name>.type` | Provider type: `openai_legacy`, `anthropic`, etc. |
| `providers.<name>.base_url` | API base URL |
| `providers.<name>.api_key` | API key |

## Usage

### Basic Usage

```bash
# Start interactive session
kxns

# Run with a prompt
kxns -p "Analyze this codebase for security vulnerabilities"

# Continue previous session
kxns --continue

# Use specific session
kxns --session <session_id>
```

### Shell Mode

Press `Ctrl-X` to switch between agent mode and shell mode. In shell mode, you can run shell commands directly.

### MCP Support

Manage MCP servers:

```bash
# Add MCP server
kxns mcp add --transport http server-name https://mcp.example.com/mcp

# List MCP servers
kxns mcp list

# Remove MCP server
kxns mcp remove server-name
```

### Web UI

Start the web interface:

```bash
kxns web
```
